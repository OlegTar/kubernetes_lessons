Кратко:
- Получить кластер Кубернетеса в каком-то облаке
- Скачать конфиг кубернетеса на комп, получить его base64
- Проставить секрет в Гитхабе KUBE_CONFIG=
- Получить Personal Access Token на DockerHub
- Проставить секрет в Гитхабе DOCKER_TOKEN
- Проставить переменную окружения в Гитхабе DOCKER_LOGIN 
- Настроить .github/workfow/docker.yaml
